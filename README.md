# Crate Design System

**Crate** is the design system for [Cargoz](https://cargoz.com) — a coded, reusable UI
foundation built fresh from the Cargoz brand. It ships **design tokens** (as CSS custom
properties) and a **React + TypeScript component library**, documented in **Storybook**.

Built so the same rules apply on every screen: 16px minimum body text, high contrast,
neutral-led UI with one restrained accent, RTL-ready (English + Arabic), light/dark
theming, and structural trust signals.

## Quick start

```bash
npm install        # install dependencies
npm run tokens     # generate src/styles/tokens.css from tokens/*.json
npm run storybook  # open the living documentation at http://localhost:6006
```

## How it's organized

| Layer | Where | What it is |
| --- | --- | --- |
| **Tokens (source of truth)** | `tokens/*.json` | Hand-edited JSON. Colors, type, spacing. **Edit these.** |
| **Tokens (generated)** | `src/styles/tokens.css` | CSS variables generated by `npm run tokens`. **Never edit by hand.** |
| **Theme** | `src/theme/` | `ThemeProvider` sets light/dark + text direction (LTR/RTL). |
| **Primitives** | `src/primitives/` | Layout building blocks: `Box`, `Stack`, `Inline`. |
| **Components** | `src/components/` | `Button`, `Input`, `Card`, … one folder each. |
| **Patterns** | `src/patterns/` | Cargoz-specific compositions: listing card, search bar, trust badges. |
| **Docs** | `stories/` | Storybook foundation pages and guidelines. |

## The 3-tier token model

1. **Primitives** — raw ramp values (`--crate-primary-600`). The only place a color value lives.
2. **Semantic** — role names components use (`--color-action`, `--color-text-primary`). These flip between light and dark.
3. **Component** — per-component knobs (`--button-primary-bg`).

Change a color in one place at the semantic tier and the whole system reskins.

## Changing a token (for designers)

1. Open the relevant file in `tokens/` (e.g. `tokens/primitives.json` for colors).
2. Edit the value.
3. Run `npm run tokens`.
4. Run `npm run storybook` to see the change everywhere.

Exact color values come from the Cargoz Figma palette — see `tokens/README.md`.

## Naming

- **Primary** = the teal/green ramp · **Secondary** = the purple ramp · base step = **600**.
- **Manrope** for headings, **Lato** for body/UI.
